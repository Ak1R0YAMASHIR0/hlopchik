# Кофейня «Хлопчик»

Учебный проект по техническому заданию: интернет-кофейня с меню, корзиной,
личным кабинетом, обратной связью и панелью администратора.

Сайт сделан на чистых HTML, CSS и JavaScript — без фреймворков и сборки.
Роль серверной части играет `localStorage`, каталог товаров хранится в формате
JSON (`js/data.js`), пароли — в виде соли и хеша (учебная имитация).

**Демо (GitHub Pages):** https://ak1r0yamashir0.github.io/hlopchik/

---

## Запуск

**Способ 1 — просто открыть файл**

Двойной клик по `index.html`. Все скрипты подключены как обычные (не модули),
поэтому сайт полностью работает по протоколу `file://`.

**Способ 2 — локальный сервер**

Из папки проекта:

```bash
python -m http.server 8000
```

и открыть <http://localhost:8000>. Подойдёт любой статический сервер — серверная часть не нужна.

> Шрифты (Cormorant Garamond, Golos Text, Caveat) подгружаются с Google Fonts.
> Без интернета сайт останется работоспособным — включится системный fallback.

## Реализация по ТЗ

**2.1. Меню**
- карточки с иллюстрацией (или фото), названием, описанием и ценой;
- фильтрация по категориям «Кофе», «Десерты», «Завтраки»;
- поиск по названию, счётчик найденных позиций, пустое состояние.

**2.2. Корзина**
- добавление и удаление товаров;
- изменение количества кнопками «−» и «+»;
- подсчёт суммы, доставка 199 ₽, бесплатно от 1 500 ₽, самовывоз бесплатный;
- оформление заказа: имя, телефон, e-mail, адрес, оплата, комментарий;
- клиентская валидация всех полей.

**2.3. Личный кабинет**
- регистрация и авторизация;
- история заказов со статусами;
- редактирование имени, телефона и e-mail;
- выход из аккаунта.

**2.4. Обратная связь**
- форма сообщения администрации (имя, e-mail, тема, текст);
- контактная информация: адрес, телефон, часы работы, карта проезда.

**3. Роли**
- гость — просмотр меню и оформление заказа без аккаунта;
- авторизованный пользователь — история заказов и редактирование профиля;
- администратор — просмотр заказов, смена статусов, сообщения, CRUD товаров.

**4. Технические требования**
- HTML + CSS + JS, без серверной части;
- данные в `localStorage`, каталог — JSON;
- клиентская валидация форм;
- имитация хеширования паролей (соль + FNV-1a/djb2, без криптостойкости);
- тёплая кофейная палитра: кремовый, бежевый, коричневый, терракота.

### Ключи localStorage

| Ключ | Что хранит |
|------|------------|
| `hlopchik.products.v1` | каталог после правок из админки |
| `hlopchik.cart.v1` | корзина: `[{ id, qty }]` |
| `hlopchik.users.v1` | пользователи: имя, контакты, соль и хеш пароля |
| `hlopchik.session.v1` | текущая сессия `{ userId }` |
| `hlopchik.orders.v1` | заказы с составом, суммой и статусом |
| `hlopchik.messages.v1` | сообщения из формы обратной связи |
| `hlopchik.seeded.v1` | флаг первичного заполнения демо-данными |

Сбросить всё: DevTools → Application → Local Storage → удалить ключи
`hlopchik.*` и обновить страницу.

## Заметки

**Фотографии.** У товара есть поле `image` — путь к файлу или ссылка.
В эталонном каталоге `js/data.js` прописаны пути к заглушкам
`images/menu/<id>.jpg`. Старые записи в `localStorage`, где хранился только
символ `art`, автоматически получают нужную заглушку по таблице в `app.js`.

**Каталог.** `js/data.js` — эталонный список. Любое изменение из админки
сохраняется в `hlopchik.products.v1` и перекрывает эталон; кнопка
«Сбросить каталог» возвращает исходные 11 позиций.

**Пароли.** Хеш считается от соли и пароля двумя некриптографическими
функциями (FNV-1a и djb2). Это именно имитация для учебного проекта:
в открытом виде пароль не хранится, но настоящей защитой такая схема не является.

**Оформление.** Печатная «бумажная» эстетика: кремовая бумага с зерном,
тонкие линии, крупная антиква, терракотовые акценты и рукописные пометки.
Вместо стоковых фотографий в макете стоят аккуратные заглушки — их можно
заменить своими снимками, не трогая вёрстку.

## Проверенные сценарии

- поиск и фильтрация в меню, добавление товара в корзину;
- изменение количества, пересчёт итога, удаление позиции;
- валидация и успешное оформление заказа (номер, статус «Новый»);
- вход с неверным и верным паролем, регистрация, редактирование профиля;
- смена статуса заказа и отметка сообщения в админке;
- добавление, редактирование и удаление товара;
- отправка сообщения через форму обратной связи с валидацией;
- адаптивная вёрстка на ширинах 1440, 1024, 768 и 390 px.
